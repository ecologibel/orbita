getting started

Use the sidebar to move between tools. The layers button at the top returns to the dashboard. Click to dos to open its views, then choose a view; the list folds away after you choose one.

Your content is saved in this browser. Sign in to Google Drive sync to keep supported data available on your other devices. Display preferences stay on each device.

The controls at the bottom of the sidebar switch between dark and light mode, change text size and page width, open this help, play ambience, and show sync status. Hover over or click the speaker icon to choose an ambience sound, set its volume, or start and stop it; it turns teal while ambience plays. Menus and view pickers close when you leave their page.

dashboard

The dashboard is the home page. Open notes or a to dos view from its tool buttons. Its at a glance list groups dated tasks due today, tomorrow, later this week or next week. You can tick a task there or add one for today.

Drag the divider beside the at-a-glance list to resize it. Use the fold control to hide or show the list.

notes

organise notes

The notes page starts with new (+ new folder, + new note and + new code), then recent, the four notes edited last (pinned notes aside), then folders: a tree of folders, then notes, then + new note and + new code. Click a folder to open it and see its subfolders and notes, indented beneath it; several folders can be open at once. Drag notes or folders to move them, and use a folder's ⋯ menu to rename it, add a subfolder, or choose its icon and colour. A folder's colour shows on everything inside it, unless a note has its own. Ctrl+Z and Ctrl+Y undo and redo moves, renames and colours.

The sidebar on the right holds search notes, with matches listed as you type, and below it sorting, tags, pinned notes and the bin. Drag a note onto pinned to pin it, or onto the bin to delete it. Open the bin to see what's in it; it keeps deleted notes for 30 days.

code

Code items hold R, with syntax highlighting, matching and rainbow brackets, and line numbers. They sit in folders beside notes and sync with them. Use copy code or download .R in the item's ⋯ menu. What was in the old codepad now lives in a code item called codepad.

write and format

Type / in a note to choose a block type. Common shortcuts include [] for a to do, /tog for a toggle, /tab for a table, and ``` for an R code block. Markdown shortcuts such as # for a heading and - for a bullet list are also available.

Select text to use the floating format menu, or use Ctrl+B for bold, Ctrl+I for italics, Ctrl+E for inline code, and Ctrl+K for a link. Drag blocks by their handle; use Tab and Shift+Tab to change indentation. Ctrl+Z and Ctrl+Y undo and redo.

Each note can have a date, tags, and a pin. Click a note's date to confirm or change it with the calendar. Click a date token such as @today or @friday in a note to-do to see the date it resolves to and adjust it. Those linked tasks appear in the to dos and dashboard; notes remain their source of truth.

to dos

Choose one of six views:

  • simple: a flexible list.
  • dates: tasks grouped by date or date range.
  • week: tasks grouped by day, with a section for unscheduled tasks.
  • month and year: calendar views.
  • done: completed tasks grouped by day.

Add @today, @friday, or @next week to a task to give it a date. Weekdays accept short names: @fri and @this fri mean the coming Friday, @last fri the previous Friday, and @next fri the Friday of the following week. For a calendar date, use @6 nov, @nov 6, or add its weekday and year, such as @fri 6 nov 2026. ISO dates such as @2026-11-06 are also accepted. Add a #tag to group related tasks. Relative date tokens stay anchored to the date you chose, while their labels roll as days pass—for example, @today becomes @yesterday the next day.

Press Enter to add a task below the current one; pressing it in the middle of a task splits the text. Drag a task by its handle to move or indent it. Select multiple tasks with Ctrl+click or Shift+click; Ctrl+C copies the selection and Ctrl+A twice selects the whole view.

Click a date token in a task to see the date it resolves to and change it with the calendar. Date ranges show separate start and end dates. Deleting a task or date section shows an undo option briefly.

focus

Choose one of today's or overdue tasks, search for another task, or type a new one. Add optional subtasks and use the timer controls to start, pause, or reset the countdown. The timer continues when you visit another page; the sidebar shows the remaining time.

Press Esc or choose leave focus to return to your previous page.

The settings sidebar sets the timer, the chime, and ambience. Ambience keeps playing as you move between tools, fades out when the timer ends, and can start by itself with the timer.

Google Drive sync

Choose the sync control at the bottom of the sidebar and select the Google account to use. Sync stores the app's files in a private app-data folder in Drive; orbita does not use this access to browse your other Drive files.

Notes (code items included), to dos, and timekeeper settings sync as separate files. Dashboard and focus can sync to dos and notes too. The focus timer itself stays on the device.

Timekeeper's tags, colours, and calendar choices sync with this Drive account, not the Google account you connect for Calendar, so the two can be different. Its sidebar width and fold stay on each device.

If local and Drive copies have conflicting changes, the sync icon turns yellow. Click it to choose local (this device's copy) or drive (Google Drive's copy), or close the window to decide later. A recovery copy is made before resolving it. If a sync replaces a newer copy, you can restore the earlier one from backups.

Sync requires the hosted site or a local web server; it does not work when you open an HTML file directly using file://. The sync icon is teal while sync is running and orange when it isn't (signed out, or the last sync failed); hover over it to see its status. Alt-click it to sign out.

If you use more than one Google account, select the account you want for Drive when the Google sign-in window appears. It can be different from an account you use with another Google service.

backups

orbita keeps a copy of your data in this browser before sync replaces it, when two devices' changes conflict, and when saved data can't be read. These copies stay on this device and are not synced.

Restoring a sync backup replaces that tool's current data and syncs it as your newest edit. Your current data is kept as another backup first. Copies of data that couldn't be read can only be downloaded, to look at or to send for help.

keyboard shortcuts

  • Ctrl+K opens the quick switcher from any tool.
  • In notes, Ctrl+B, Ctrl+I, Ctrl+E, and Ctrl+K format selected text or add a link.
  • In lists, Enter creates a task below; Esc leaves focus mode.
For people hosting their own copy

This section is for the person configuring a separate orbita installation. It is not needed to use the hosted app.

  1. In Google Cloud Console, create a project and enable the Google Drive API.
  2. In Google Auth Platform, configure the app as external. Add your account as a test user while the app is in testing.
  3. Add the https://www.googleapis.com/auth/drive.appdata scope.
  4. Create a web OAuth client. Add the exact site origin (for the hosted site, https://ecologibel.github.io; for local testing, the origin might be http://localhost:8000 or http://localhost:8001). Do not add a path or trailing slash.
  5. Set the client ID in the app's sync configuration. Do not put the client secret in client-side code.
