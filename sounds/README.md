# Sounds

Recordings for the focus ambience. Waves is made in the browser by
`sounds.js`, so it needs no file here. `sounds.js` sets each one's level so
they play at about the same loudness (nature a little softer).

| File | Used for | Source | Author | Licence |
|---|---|---|---|---|
| `cafe.ogg` | café | [Restaurant ambience.ogg](https://commons.wikimedia.org/wiki/File:Restaurant_ambience.ogg) | stephan | Public domain |
| `fire.ogg` | fire | [Dry grass burning in open fireplace.ogg](https://commons.wikimedia.org/wiki/File:Dry_grass_burning_in_open_fireplace.ogg) | ezwa | Public domain |
| `rain.mp3` | rain | [Bourne woods rain 2020-05-10 0800.mp3](https://commons.wikimedia.org/wiki/File:Bourne_woods_rain_2020-05-10_0800.mp3) | Robert EA Harvey | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| `bushland.webm` | nature | [Sonus naturalis - Soundscape XC568248.mp3](https://commons.wikimedia.org/wiki/File:Sonus_naturalis_-_Soundscape_XC568248.mp3) (eucalypt forest, Faulconbridge, Blue Mountains, NSW) | James Ray | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |

Changes from the originals:

- `rain.mp3`: the first 8 seconds, which were silent, cut off (whole MP3
  frames copied, not re-encoded), so rain starts straight away.
- `bushland.webm`: six minutes (13:00 to 19:00) of the 36-minute original,
  chosen as the calmest stretch, with the end crossfaded over 3 seconds into
  the start so it loops smoothly, and re-encoded as Opus at 64 kbps.
- `cafe.ogg` and `fire.ogg` are unchanged.

All were downloaded from Wikimedia Commons on 5 November 2026. The CC BY-SA
recordings are also credited on the help page.
